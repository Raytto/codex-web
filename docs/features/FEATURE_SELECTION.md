# 账号功能选择

个人设置 → **功能选择** → **项目看板**。所有账号默认不勾选；需要时主动勾选开启。未勾选时隐藏看板侧栏、看板搜索结果、看板页面和关联/收录入口。文件夹工程、任务、搜索和普通会话继续使用。关闭开关时退出正在显示的看板，再次勾选可重新进入。

这是显示偏好：不会删除看板、项目、资料或会话关联，也不会撤销已有主项目的任务背景。正在运行的任务不受影响。隐藏后“新建项目”直接进入文件夹工程创建，不再展示看板类型选择。

## 持久化与同步

- 使用原有 SQLite `user_settings` 的 `feature_selection` 键，每账号一条 JSON（`paraBoard`、`revision`）；无新增表或数据库。没有设置的账号返回 `false / 0`。
- 一次性迁移 `2026093003 / para-default-hidden` 将现有已保存的功能选择统一关闭并递增 revision，避免旧客户端写入覆盖；未保存的账号使用关闭默认值。迁移只执行一次，之后用户主动开启的选择不会因重启再次被关闭。
- 登录和会话恢复携带当前设置。`GET /api/user-settings/features` 读取；`PUT` 接收布尔值及当前 revision，由已认证账号决定归属，沿用 CSRF 检查。事务比较 revision，陈旧写入返回 409，不覆盖另一客户端的最新选择。
- 成功保存后向该账号已有的 `/api/system/events` 连接发送 `feature_selection`；重连也发送当前值。客户端只采用不早于当前 revision 的状态，迟到读取和写回执不回滚新值。
- 页面恢复可见、获得焦点、联网时，以及可见页面每 30 秒补读。独立阅读页使用相同账号偏好和补读路径。请求有 12 秒上限；保存期间防重复提交并保留键盘焦点，失败提示后读取服务器实际状态，允许重试。
- 此偏好不是权限隔离或服务器禁用开关；既有数据 API 和已有会话关联语义保持不变。

## 验证入口

`tests/feature-selection.test.ts` 验证默认值、不同会话/账号、认证与 CSRF、非法输入、版本冲突、SSE 账号边界、重连及重新打开数据库后的持久化。

`tests/browser/feature-selection.mjs` 用两个独立浏览器 context 操作真实 API，覆盖开关、当前看板退出、搜索、数据保留、刷新、迟到响应、503 后重试、断线返回及 390/320/深色/键盘。仅创建本轮测试对象；finally 恢复原开关并删除自身业务对象，幂等收据按安全 report 的账号与 requestKeys 定向收尾。不会启动模型或语音。手机视口不代表真实 iOS Safari。

`tests/browser/feature-default-off.mjs` 先在不写入设置的情况下确认账号开关未勾选、刷新后仍隐藏，再执行上述完整流程并恢复关闭。迁移回归覆盖原已开启、已关闭、缺失/无效设置，以及迁移后的主动开启跨重启保留。
