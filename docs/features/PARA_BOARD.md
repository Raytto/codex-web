# PARA 看板基础版

实现范围：看板与工程并列；想法、酝酿、进行中、已完成；独立暂停/归档；轻量领域；独立资源库；跨工程会话关联；项目简报和选定资料创建工作会话草稿。阶段不随 Job 状态自动改变。

## 使用与边界

侧栏「PARA 看板」标题右侧「… → 新建看板」打开创建入口；「文件夹工程 → … → 新建项目」仍可选择两种类型。想法只需标题，不创建工程或会话。项目详情维护简报、下一步和默认工程；会话可保留一个主工作项目和多个参考关联。主项目背景在发送时保存快照；参考关联不会进入输入。

看板与文件夹工程处于同一侧栏滚动区，标题、菜单右边距与行距统一；搜索与账号入口保持可访问。看板行「…」提供改名、归档与恢复；已归档看板可确认删除，非空看板会拒绝删除并保留所有项目/资料。六点手柄支持触摸拖动，桌面支持整行拖动；聚焦手柄后可用上下键排序。排序按账号保存到服务器，刷新或换设备仍有效；仅在看板间移动，不改变文件夹工程顺序。

「记个想法」与资料正文的语音输入复用聊天的录音 Hook 和波形面板。话筒位于输入区右侧，录制显示实时波形、时长、取消、停止；停止后转写并追加到最新文字，不覆盖录音中键入的内容，也不自动提交。失败音频按账号和看板/资料入口保留本机草稿，可重开后重试或删除，沿用聊天的十分钟上限及幂等录音 ID。识别中阻止关闭和保存；关闭正在录制或等待权限的弹窗会释放麦克风。超过标题上限的识别文字保留并提示精简，不截断。

项目卡片、详情与阶段筛选复用聊天 `SettingMenu`，显示高亮与勾选，并支持方向键/回车/Escape。阶段面板通过定位浮层避开卡片和滚动区裁切，支持窄屏。

新会话工程按本次选择、项目默认、看板默认、账号默认依次继承。指定工程失效或机器离线时拒绝创建，不隐式回退。选择「设为项目默认」才修改后续默认。看板入口显式创建新会话并用账号作用域请求键幂等；普通侧栏不会复用已有关联的空会话。

从消息、附件卡片、已登录阅读页「加入项目」，或在资料页上传。正文可保留本机草稿，服务器确认收录才显示资料。链接只存 URL/备注；单份文件上限 64 MiB，每次一个，失败可重试。新会话最多选 12 份资料，文件复制到正常会话附件并重新校验 SHA-256；选定文字及版本进入可编辑草稿，创建不会自动启动任务。普通服务器工程与 显式配置的宿主执行器均复用现有附件执行链。

首版远程工程只接收简报、索引和选定文字；有文件选择时明确阻止创建，需取消文件或改选服务器工程。未实现跨机器资源文件投递、Agent 项目写入工具、自动提炼结论与建议、接力新会话自动继承关系；既有同一会话自动续跑按发送时主项目快照继续。Linux 手机视口验收不等同于 iOS Safari 真机。

资料预览支持 Markdown、纯文本、HTML 隔离预览、常见图片和 PDF；其他格式可下载或作为附件交给 Agent。独立资源尚未接入原阅读器的分页/标注/进度与 EPUB 渲染。HTML 无脚本权限且禁止外部加载。资料范围与下载均按当前账号校验。

普通会话的关联项目从侧栏会话行或当前会话右上角「… → 关联项目」查看与修改，聊天顶部不再显示常驻关联栏。弹窗支持项目直达、添加关联、设为主项目及确认取消关联；操作对象为打开菜单的会话，无须先切换当前聊天。取消关联不删除任何会话或项目。

## 存储与恢复

增量迁移 `2026092903 / para-board-v1` 建立 `para_*` 表；不改旧工程、会话或文件 ID。资源属于账号和看板，可被多个项目引用；文件保存在该账号的 `para-resources/<uuid>/content`，不以伪会话作容器。收录复制、哈希确认后事务登记，失败回滚本轮文件；创建请求回执支持丢失响应后的重试，包括原来源已经删除的情况。资源文本保留历史版本，简报/阶段操作保留项目事件快照。

`2026093001 / para-board-order` 只为看板增加 `position`，旧看板初次迁移保持创建顺序。排序在事务内按源/目标 ID 移动并重新编号，校验双方账号归属，保留未显示的归档项，重复相同操作不改变 revision；改名/归档继续使用版本校验。旧程序可忽略新增列，程序回滚不自动回滚业务库。

文件计入账号既有存储额度。原会话删除或冷存储不会删除独立资源；来源外键删除后变为空，保留来源标题。冷存储来源收录时先触发原恢复流程并提示重试；看板浏览不读取/恢复历史会话正文。独立资源首版长期本地保留，只有主动归档、解除所有引用再显式删除才清理；没有自行冷归档承诺。

独立资源文件保持私有。带入会话时，以普通上传相同的文件创建方式继承目标账号目录 ACL，再校验附件哈希；不复制原件的 `0600` 模式，避免屏蔽普通租户执行 UID 的读取权限。跨账号目录访问边界保持不变。

进程启动只清理超过 24 小时的本模块暂存文件及无数据库引用的 UUID 资源目录；不碰有效引用或其他租户文件。资源路径拒绝符号链接跨目录。独立资源位于现有 tenants 持久卷，应包含在 tenants 备份中；回滚程序不会恢复旧数据库。可在应用配置中设置 `CWW_PARA_ENABLED=false` 关闭 PARA 路由，数据保留。

## 一致性与授权

沿用已有登录、CSRF、同源检查。看板、领域、项目、文件、消息和会话每次关联均校验账号；看板关系不增加执行工程的授权。一个会话最多一个主项目由唯一索引保证。改主项目显式将旧关系降为参考；取消关联不删除原会话。

表单固定编辑起点版本，服务端拒绝旧 revision。简报冲突时显示最新简报并保留本机输入，用户对照后明确采用新版再保存。页面每 15 秒刷新当前看板，当前窗口的成功操作立即刷新；正在编辑的简报不被后台刷新替换。

简报、阶段与撤销保存后立即采用服务器回执中的项目版本，并丢弃此前发出的刷新结果。下一次操作不必等待轮询，慢网络下连续保存/换阶段也不会带入刚被自己更新过的旧版本。

Job 和 pending prompt 的项目背景分别在创建时持久化；队列转 Job 搬运已接受的快照，不读取最新简报覆盖。已开始任务不受后续关联/简报变动影响。请求内容改变时不能复用同一个幂等键。归档项目遇到运行/续跑时需要明确确认，且不取消原任务。

## 验证入口

`tests/para.test.ts` 验证真实路由授权、幂等、版本冲突、主/参考隔离、文件长期保留、输入复制校验、失败回滚、额度、队列与重开数据库、离线工程和状态独立。主应用标准门禁仍为 `npm test`、`npm run lint` 和 Docker test stage。

浏览器验收须覆盖桌面、390/320px 布局、表单键盘操作、并发编辑、阶段/撤销、领域/资料/成果、关联双向跳转、创建草稿、归档/恢复；如另行启用模型验收，应只使用合成内容并清理临时会话。测试数据应使用唯一前缀，通过真实 API 清理。

`tests/browser/para-interactions.mjs` 覆盖菜单新建/改名/归档恢复、鼠标/触摸/键盘排序、整栏滚动、刷新保序、阶段菜单与完成、空看板删除/取消及非空拒绝，另验收话筒尺寸、波形、权限拒绝/延迟关闭、录音取消、录制中输入、失败音频重开后重试、手机及深色布局。音源为测试合成语音，经真实 Web Audio/MediaRecorder 编码；本地使用 stub ASR；真实识别服务需管理员另行配置后单独验收。不是实机麦克风或 iOS Safari 验收。

阶段菜单的浮层在触发按钮实际移动或超出视口时收起；浏览器聚焦按钮后的延迟滚动通知、无关侧栏滚动不会误关。浏览器回归包含手机切换桌面后立即打开阶段菜单，以及位置未变化时的滚动通知。
