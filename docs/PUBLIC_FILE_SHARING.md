# HTML / Markdown 公开分享

阅读器的「设置 → 分享」默认开启 30 天，显示剩余时间和具体到期时间；个人设置的「公开分享管理」也可查看期限、续期或关闭。点击「续期 30 天」从当前时间重新计算 30 天，不在原期限后累加。到期后必须由文件所属账号显式「重新开启分享」；关闭、续期、重新开启沿用原固定链接。

所有文件默认私有，只有已交付的不可变 HTML/Markdown 成品（不超过 5 MiB）及其明确引用、同次交付的安全图片可公开。文档和配图的每次匿名请求（包括 HEAD）均核对期限，`now >= expires_at` 即拒绝；不依赖浏览器、后台扫描或账号在线。公开响应 `Cache-Control: no-store`，已打开的公开页沿用每分钟及恢复焦点时的权限复查。访问不会续期，也不制造会话的私人活跃动作。

数据库迁移 `2026093005/public-share-expiry` 为 `public_file_shares` 增加 `expires_at`。一次性将所有原本开启、没有期限的分享设为迁移时刻起 30 天；原已关闭分享保持关闭。重启不会延长期限。数据库的 `enabled` 保留用户开关意图，实际公开状态始终是 `enabled=1 AND expires_at>now`；到期资源映射可保留供审计，但不能授权访问或阻挡冷存储。

## 到期后的冷存储

有效分享及其配图保留本地；到期或主动关闭后不再受分享保护。普通会话仍需超过 15 天无活动；主动归档的会话不等待该期限，运行任务、草稿、待发消息、wake 等原有门禁仍生效。只有另行完整配置冷存储及维护计划后，达到条件的文件才由该计划处理；因此到期后何时归档取决于这些条件，不保证再额外等待 15 天。

会话已冷存储、但当时因分享而留在本地的文件，也会重新进入候选。归档器在同一个会话锁内恢复、核验旧代次，然后把旧内容和到期文件合并为新代次；上传、回下载校验成功前不替换旧云端清单。失败保留原代次及本地文件，后续可重试。成功后新本地隔离副本继续保留 7 天。云端使用 age 密文和 SHA-256 核验，详见 [会话冷存储](CONVERSATION_COLD_STORAGE.md)。

续期的数据库事务与归档状态转换串行化：归档/恢复中拒绝开启或续期并提示重试，避免续期成功的文件被归档移走。冷存储文件需要先在私人阅读器中恢复，随后可重新开启公开分享。

## 回归与验收

- `tests/public-share-expiry.test.ts`：精确期限边界、旧数据迁移、重启不续期。
- `tests/app.test.ts`：真实路由的 HTML/Markdown、配图、续期/重启分享、权限/CSRF 和归档冲突。
- `tests/conversation-cold-storage.test.ts`：到期残留文件合并归档、上传失败保留旧代次、恢复完整内容。
- `scripts/check-public-share-expiry.mjs`：构建后运行隔离真实应用的桌面 1440、手机 390/320 视口交互；指定 `PLAYWRIGHT_MODULE` 和 `CHROMIUM_EXECUTABLE`。
- `scripts/public-share-expiry-scenario.mjs` 可在独立测试部署复用，使用普通密码登录及仅限本次新建会话的成品和期限夹具；不调用模型，清理本次会话、成品及分享审计。

到期验收移动专属测试文件的期限，不改变系统时钟、不等待真实 30 天、不修改用户既有分享。Linux Chromium 手机视口不等于 iOS Safari 真机验收。
