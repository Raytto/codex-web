# 项目周期任务

2026-10-10。周期计划属于项目，独立于每一次执行的会话和 Job。用户停止某次会话、执行失败或应用重启，均不删除日程；只有暂停、删除或达到总次数才停止未来触发。

## 交互

- 项目三点菜单 → **管理定时任务**，始终可见。管理页显示项目所有周期任务和仍在等待的会话延时任务。
- 项目存在周期任务时，侧栏会话列表首行显示 **周期任务（N）**，包含启用、暂停和达到次数的未删除任务。展开后点击任务，在右侧主区域查看/编辑详情。无周期任务时不占用侧栏行。
- 支持名称、指令（最多 20000 字）、模型、思考深度、时区、固定分钟间隔/每天/每周多日/每月日期、不限或指定总次数，以及最近 50 条触发记录。
- 每次触发在原项目创建独立会话，使用触发时保存的模型、深度和指令快照。历史会话不因任务编辑或删除而改变。可从执行记录打开会话。
- 原有“在本会话延时继续”和“立即新建会话并延时继续”沿用一次性 wake plan。创建入口仍在会话菜单。
- 本版由网页创建和编辑周期计划。Agent 的 `pp_agent_schedule_wait` 仍只安排一次性续跑；周期计划不靠 Agent 自行续建。

设计参考：[OpenAI Scheduled tasks](https://learn.chatgpt.com/docs/automations) 的独立计划、每轮新会话、任务设置与运行记录管理；日程和队列实现由 Codex Web 自己持久化。

## 调度与恢复

`recurring_tasks` 存日程、下一次到期时间、总次数、已安排次数及 revision；`recurring_runs` 存每次到期和对应会话。增量迁移 `2026101001` 只增加表及索引，不修改旧等待计划。

现有服务器每秒扫描器读取到期索引。每条计划在 `BEGIN IMMEDIATE` 中重新核对启用/到期条件，同时创建会话、pending prompt、运行记录并推进下一次时间。唯一键 `(task_id, scheduled_at)` 和同一事务阻止重复触发；事务异常全部回滚。派发复用已有普通队列、执行器可用性、容量和维护门。

同一计划只允许一个尚未结束的执行：排队、运行或会话中的一次性等待均算占用。若上一轮仍占用，到期记录为“跳过”，不增加已安排次数，也不堆积新会话。停止或失败结束占用，后续日程正常触发。其他周期任务互不阻塞。

停机错过多个时间点时只补一个到期执行，随后计算当前时刻之后的下一时间。固定间隔以保存的到期时间为锚点，不因执行时长漂移。每天/每周/每月按 IANA 时区计算：月内不存在的日期跳过；夏令时不存在的墙上时间跳过；重复出现的墙上时间仅采用第一次。恢复启用从当前时刻之后安排，不补暂停期间的轮次。

次数统计在创建执行会话时增加，包括之后失败/停止的轮次，不以模型成功回复计数。达到次数意味着不再安排新轮次，最后一次会话可能仍在执行。若需再次启用，先提高次数或改为不限次数。

暂停/删除不取消已有会话。归档项目之前必须暂停其中的启用计划；归档后调度器不会触发其计划，恢复项目也不自动启用被暂停的计划。

## API 与边界

浏览器 API 均位于既有 session + CSRF 中间件之后；读写按账号和项目归属过滤。修改、切换状态和删除需要 revision，陈旧编辑返回 409。暂停不校验旧模型，保证模型下架后仍可停止计划；启用检查当前模型目录。

- `GET /api/recurring-tasks`：当前账号可见项目内的计划。
- `POST /api/projects/:id/recurring-tasks`：创建；每项目最多 100 个未删除计划。
- `GET/PATCH/DELETE /api/recurring-tasks/:id`：详情与历史、编辑、软删除。
- `POST /api/recurring-tasks/:id/state`：暂停或启用。
- `GET /api/projects/:id/scheduled-waits`：当前项目等待中的一次性计划，不返回事件凭据。

周期计划支持现有本地/宿主/远端项目，远端离线时由既有队列等待重连。事件触发周期、任意 cron/RRULE、并发重叠执行不在本版范围内。

## 项目技能

现有 `.agents/skills` 管理补齐 可选宿主项目：Web 验证账号与项目归属，宿主桥再使用只读数据库核对项目属于固定宿主账号和执行器，从该项目根目录读取或操作技能。普通账号继续使用受限项目路径校验；不修改账号级技能。远端 Worker 网页技能管理暂未扩展，入口说明该边界。

大弹窗支持实际 SKILL.md 内容查看/编辑、启用/停用和删除，包含加载、错误重试、未保存确认及键盘焦点约束；选中技能时会把读取内容同步到编辑区。停用保留整个目录于现有 `.disabled` 区域；同名已停用技能会阻止重复创建。路径和技能文件不允许符号链接。

## 验证

专项测试涵盖日历/时区/DST、同时间重复扫描、独立连接与重开数据库、停止/失败后的下一轮、长期离线占用、停机补一次、事务异常回滚、模型与深度快照、次数与暂停/恢复、陈旧编辑、CSRF、跨账号隔离及归档门禁。正式发布还需完整构建/应用测试、容器门禁及真实登录后的桌面/手机视口验收。每个自托管实例仍须验收自己的部署、时区和执行器配置。
