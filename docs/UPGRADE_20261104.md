## Installation and upgrade

Keep the base installation in the English or Chinese README and [build/storage guide](BUILD_AND_STORAGE.md). `./scripts/build-image.sh` builds the tracked Git commit with the `runtime` target by default. `documents` is optional. No host npm installation, second model CLI download, or new dependency is required. Preserve your `.env` and state directories; do not copy another installation's accounts or history.

For an existing installation, drain active work, retain a verified local state/database backup and previous image, pull the reviewed `main`, build the new image, then run `docker compose up -d --no-build`. Check health, username/password login, existing conversations, a new request, and restart persistence. This release changes no schema or Worker protocol. Keep the prior image and backup until acceptance completes.
