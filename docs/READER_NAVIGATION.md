# 阅读器导航

HTML、PDF、EPUB 文件卡片和消息中的阅读器链接默认在当前标签页打开；HTML、Markdown、PDF、EPUB 的「预览」按钮以及分享管理中的文件标题、公开页入口采用相同行为。原始文件查看与下载继续使用各自既有入口；Markdown 文件卡片正文仍打开原文件，可用「预览」按钮进入阅读器。

## 返回工作站

登录阅读页、公开分享阅读页以及阅读失败状态均显示返回入口。有可用历史，且来源页与当前页同源、位于 `/codex-web` 或其子路径、不是当前页时，返回上一页。直接打开、新标签页没有来源、跨域来源或同域其他应用均回到 `/codex-web`。同域的 `/codex-web-other` 不属于本应用。返回入口不授予任何文件权限或登录状态。

## 新标签页与远程文件

- 普通阅读器链接可用 Alt + 点击另开标签页，继续保留浏览器原生 Ctrl/Cmd + 点击和中键行为。
- 远程文件卡片或正文按钮的 Alt + 点击会在用户操作期间先保留标签页，断开 opener，再等待文件传输。传输失败或结果只能下载时，关闭预留空白页。弹窗被拦截时显示错误，允许弹窗后可重试。
- 普通远程预览点击仍在当前标签页打开；专用下载按钮继续下载。

## 验收

构建与类型检查使用 `npm run verify`。设置已有 Playwright 包入口 `PLAYWRIGHT_MODULE` 与 Chromium 可执行文件 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 后，运行 `node tests/browser/reader-navigation.mjs`。脚本在回环地址提供 `/codex-web` 下的真实 UI 和合成 API，覆盖桌面与窄屏、重复打开/返回、Alt/Ctrl/中键、远程传输成功与失败、阅读失败页、直接打开、同域其他应用和公开分享入口；不访问已部署站点或真实模型。

浏览器模拟窄屏不能替代 iOS Safari 真机验收；Cmd 键与系统浏览器快捷键需在对应设备单独检查。阅读正文/选区回归另见[逐图阅读](READER_PROGRESSIVE_LOADING.md)。
