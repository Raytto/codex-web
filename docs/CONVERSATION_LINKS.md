# Stable conversation links

Copy a conversation link from its action menu to retain its ID in the URL under the configured base path. Opening the link restores its project and conversation; browser Back and Forward follow navigation history. Ownership checks still apply, and an inaccessible link produces a visible recovery state rather than selecting unrelated history. Archive/cold-restore waits preserve the selected conversation through transient errors. A conversation link is an authenticated navigation link, not an anonymous public share.
