# HTML / Markdown 正文优先阅读

登录阅读页先显示正文，再按文档顺序加载图片。前一张成功、失败或超时后再处理下一张；单张图片等待上限为 15 秒。关闭或切换文档会停止旧队列。图片补载不重建正文节点，避免丢失原生选区和已回放的标注；PDF/EPUB 仍使用原有分页流程。

内嵌 Base64 图片由服务端替换成与该文件版本绑定的图片地址，按需读取。正文缓存只保存文字与字节位置，最多 8 MiB、16 份文档，同时完整解析最多 4 份、每份不超过 100 MiB。认证正文与图片接口检查账号归属、普通文件及版本；公开图片额外检查分享是否仍有效。缓存命中也不会绕过这些检查。公开分享的成品大小限制仍为 5 MiB。

原文件下载不改写内容。在线阅读中的「加入项目」移至设置菜单，并遵循账号的项目看板显示偏好。该偏好隐藏入口，不删除原有关联。

## 验证

`tests/reader-text-resources.test.ts` 覆盖文本/图片分离、并发缓存、文件更新、非法范围、账号隔离、公开分享关闭及到期。构建后使用已有 Playwright 与 Chromium 执行 `tests/browser/reader-progressive-images.mjs`，验证 HTML/Markdown 在桌面和手机视口下的正文首显、顺序加载、坏图继续、原生选区、标注和菜单。手机视口不能替代真机 iOS Safari 验收。
